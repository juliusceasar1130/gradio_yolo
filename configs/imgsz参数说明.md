# imgsz 参数说明

**更新时间**：2025年1月27日

---

## ❓ 常见问题

### Q: `imgsz` 参数是否需要与输入图像的原始尺寸一致？

**A: 不需要！** ✅

---

## 📖 详细说明

### 1. `imgsz` 的作用

`imgsz` 参数指定的是**模型推理时会将图像调整到的尺寸**，而不是要求输入图像的原始尺寸必须匹配。

**工作流程**：
```
输入图像（任意尺寸） → YOLO自动resize到imgsz → 模型推理 → 结果映射回原始尺寸
```

### 2. 关键要点

#### ✅ 不需要匹配输入图像尺寸
- 输入图像可以是任意尺寸（如 1920x1080、800x600 等）
- YOLO会自动将图像resize到 `imgsz` 指定的尺寸进行推理
- 检测结果会自动映射回原始图像尺寸

#### ⚠️ 建议与训练时的尺寸一致
- **最佳实践**：推理时的 `imgsz` 应该与**训练时的 `imgsz` 保持一致**
- 这样可以获得最佳的性能和准确性
- 如果训练时使用的是 640，推理时也应该使用 640

#### 📊 尺寸选择建议

| imgsz 值 | 速度 | 精度 | 适用场景 |
|----------|------|------|----------|
| 320 | 最快 | 较低 | 实时检测、低配置设备 |
| 640 | 中等 | 中等 | **推荐默认值**，平衡速度和精度 |
| 1280 | 较慢 | 较高 | 高精度需求、小目标检测 |

## 💡 实际例子

### 例子1：输入图像尺寸与imgsz不同
```yaml
# 配置
imgsz: 640

# 输入图像
原始尺寸: 1920x1080

# 处理过程
1. YOLO自动将 1920x1080 的图像resize到 640x640
2. 在640x640尺寸上进行推理
3. 检测结果（坐标）自动映射回 1920x1080 的原始尺寸
4. 返回的检测框坐标是相对于原始图像的
```

### 例子2：训练与推理尺寸一致（推荐）
```yaml
# 训练时
imgsz: 640

# 推理时（配置）
imgsz: 640  # ✅ 与训练时一致，获得最佳性能
```

### 例子3：训练与推理尺寸不一致
```yaml
# 训练时
imgsz: 1280

# 推理时（配置）
imgsz: 640  # ⚠️ 与训练时不一致，可能影响精度
```

## 📝 注意事项

### 1. 性能权衡
- **更大的 imgsz**（如 1280）：
  - ✅ 精度更高，能检测到更小的目标
  - ❌ 速度更慢，占用更多内存

- **更小的 imgsz**（如 320）：
  - ✅ 速度更快，占用更少内存
  - ❌ 精度可能下降，小目标可能检测不到

### 2. 最佳实践
1. ✅ **推理时使用与训练时相同的 imgsz**
2. ✅ **如果训练时使用 640，推理时也使用 640**
3. ✅ **对于工具关键点检测，640 通常已经足够**

### 3. 动态调整（可选）
如果需要处理不同尺寸的图像，可以：
- 保持 `imgsz` 固定（推荐）
- 或根据图像尺寸动态调整（需要验证效果）

## 🔍 代码中的使用

在代码中，`imgsz` 参数直接传递给 YOLO 的 `predict()` 方法：

```python
# src/yolo_detector/core/detector.py
prediction_params = {
    'imgsz': params.get('imgsz', 640),  # 从配置读取
    # ...
}
results = self.model.predict(source=image, **prediction_params)
```

YOLO会自动处理图像的resize，无需手动处理。
