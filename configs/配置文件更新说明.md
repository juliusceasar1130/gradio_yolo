#### 新增 ✅

#### 配置内容
```yaml
models:
  pose:
    path: "/app/models/tool_pose_best.pt"
    type: "pose"
    description: "工具关键点检测模型"

pose:
  confidence_threshold: 0.25
  max_det: 1000
  iou: 0.45
  imgsz: 640
  device: ""
  half: false
  visualization:
    kpt_radius: 5
    kpt_line: false
    labels: true
    boxes: true
    # ... 其他可视化参数
```

**注意**：关键点配置仍位于 `datasets/tools/tool_pose.yaml`（与本地环境相同）

## 🔍 配置使用说明

### 关键点配置的位置

#### ✅ 在 `datasets/tools/tool_pose.yaml`（新位置）
- `kpt_shape` - 关键点形状 [7, 3]
- `kpt_names` - 每个类别的关键点名称
- `skeleton` - 骨架连接
- `flip_idx` - 水平翻转索引
- `pose_weights` - 关键点权重

#### ✅ 在 `configs/default.yaml`（预测参数）
- `confidence_threshold` - 置信度阈值
- `max_det` - 最大检测数
- `iou` - IoU阈值
- `imgsz` - 图像尺寸
- `device` - 设备选择
- `half` - 半精度推理
- `visualization` - 可视化参数
