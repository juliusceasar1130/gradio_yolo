# 改造一个工具关键点检测软件
## 基本思路：
  1. 实时采集摄像头数据
  2. 点击按钮开始检测
  3. 保存检测前图片
  4. 开始关节点检查
  5. 检测结果显示
  6. 保存检测结果图片和数据

1. 摄像头数据采集：采用Axis网络摄像头实时采集
2. 检测算法实现：复用D:\00deeplearn\yolo11\gradio_tool\tool_pose\demo中代码
3. 检测结果保存：复用D:\00deeplearn\yolo11\gradio_tool\tool_pose\demo中代码，适当做优化
4. 前端开发：对本项目的gradio项目进行改造，删除不相关的页面和功能
5. 要求代码简洁，容易维护，方便后续开发，注释详细
