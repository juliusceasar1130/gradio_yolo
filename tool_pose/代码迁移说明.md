# 代码迁移说明

**创建者/修改者**: chenliang  
**迁移时间**: 2025年11月02日 10:00  
**主要修改内容**: 将 `tool_pose/demo` 中被使用的模块迁移到 `src/yolo_detector` 目录

---

## 📋 迁移概述

为了提高程序结构的清晰度，将 `tool_pose/demo` 目录下被引用和复用的程序模块迁移到 `src/yolo_detector` 相应的文件夹下，并更新了所有相关的导入路径和文档。

---

## ✅ 已迁移的文件

### 1. 核心模块 (`src/yolo_detector/core/`)

#### `tool_pose_model_loader.py`
- **原位置**: `tool_pose/demo/core/model_loader.py`
- **新位置**: `src/yolo_detector/core/tool_pose_model_loader.py`
- **类名**: `ModelLoader` → `ToolPoseModelLoader`
- **功能**: 工具关键点检测的YOLO模型加载器（单例模式）
- **主要方法**:
  - `get_model(model_path, device)` - 获取模型实例（支持缓存）
  - `clear_cache()` - 清除模型缓存
  - `reload_model(model_path, device)` - 重新加载模型

#### `tool_pose_predictor.py`
- **原位置**: `tool_pose/demo/core/predictor.py`
- **新位置**: `src/yolo_detector/core/tool_pose_predictor.py`
- **类名**: `Predictor` → `ToolPosePredictor`
- **功能**: 工具关键点检测的YOLO预测执行器
- **主要方法**:
  - `predict(model, source, ...)` - 执行预测
  - `validate_results(results)` - 验证预测结果

### 2. 工具模块 (`src/yolo_detector/utils/`)

#### `tool_pose_angle_calculator.py`
- **原位置**: `tool_pose/demo/utils/angle_calculator.py`
- **新位置**: `src/yolo_detector/utils/tool_pose_angle_calculator.py`
- **功能**: 关键点角度计算和图像标注工具
- **主要函数**:
  - `load_angle_config(config_path)` - 加载角度配置文件
  - `calculate_angle(p1, p2, p3)` - 计算三点角度
  - `calculate_angles_for_object(...)` - 为单个对象计算所有角度
  - `annotate_angles_on_image(...)` - 在图像上标注角度值
  - `draw_text_with_pil(...)` - 使用PIL绘制文本（支持Unicode）
  - `get_keypoint_index_by_name(...)` - 通过名称获取关键点索引
  - `get_system_font_path()` - 获取系统字体路径

#### `tool_pose_json_utils.py`
- **原位置**: `tool_pose/demo/utils/json_utils.py`
- **新位置**: `src/yolo_detector/utils/tool_pose_json_utils.py`
- **功能**: JSON序列化和结果保存工具
- **主要函数**:
  - `convert_to_json_serializable(obj)` - 将对象转换为JSON可序列化格式
  - `save_results_to_json(...)` - 保存检测结果和角度计算结果到JSON文件

## 🔍 使用说明

迁移后，使用方式保持不变：

```python
from yolo_detector.utils import ToolPoseDetector

# 创建检测器（配置文件路径不变）
detector = ToolPoseDetector()  # 默认使用 tool_pose/demo/angle_config.yaml
# 或
detector = ToolPoseDetector(config_path="path/to/config.yaml")

# 使用方式完全相同
result = detector.detect_and_annotate(image)
```

如果需要直接使用子模块：

```python
from yolo_detector.core import ToolPoseModelLoader, ToolPosePredictor
from yolo_detector.utils import (
    load_angle_config,
    calculate_angles_for_object,
    annotate_angles_on_image
)

# 直接使用相关函数和类
```
