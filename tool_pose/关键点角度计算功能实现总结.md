## 📋 项目概述

本项目实现了基于 YOLO Pose 模型的关键点角度计算功能，能够：
- 自动检测工具对象及其关键点
- 根据预定义的角度配置计算关键点形成的角度
- 在原图上可视化标注角度值和弧线
- 输出详细的角度计算结果到JSON文件

## 🎯 实现目标

1. ✅ 从配置文件读取角度定义
2. ✅ 根据检测到的对象类别和关键点计算角度
3. ✅ 在可视化图像上标注角度值（原图坐标）
4. ✅ 输出角度结果到控制台和JSON文件

## 🔧 核心实现

### 1. 角度配置文件 (`angle_config.yaml`)

**位置**: `tool_pose/tools/angle_config.yaml`

**格式说明**:
```yaml
tool1:
  angle1: [t1_1, t1_2, t1_3]    # [起点, 顶点, 终点]
  angle2: [t1_2, t1_3, t1_4]
  angle3: [t1_3, t1_4, t1_5]
  angle4: [t1_4, t1_5, t1_6]
  angle5: [t1_5, t1_6, t1_7]
tool2:
  angle1: [t2_1, t2_2, t2_3]
  angle2: [t2_2, t2_3, t2_4]
  angle3: [t2_3, t2_4, t2_5]
  angle4: [t2_4, t2_5, t2_6]
  angle5: [t2_5, t2_6, t2_7]
```

**关键特点**:
- 每个角度由三个关键点名称定义
- 中间点为角度的顶点
- 支持多类别工具（tool1, tool2等）

### 2. 角度计算工具模块 (`angle_calculator.py`)

#### 2.1 核心函数

**`load_angle_config(config_path)`**
- 功能: 加载角度配置文件
- 返回: 角度配置字典

**`load_tool_pose_config(config_path)`**
- 功能: 加载工具姿态配置文件（获取关键点名称映射）
- 返回: 工具姿态配置字典

**`get_keypoint_index_by_name(kpt_name, kpt_names_list)`**
- 功能: 通过关键点名称字符串匹配获取索引
- 特点: 支持多类别关键点名称匹配

**`calculate_angle(p1, p2, p3)`**
- 功能: 计算三点角度（p2为顶点）
- 算法: 向量夹角公式
  ```python
  vec1 = p1 - p2  # 从顶点指向起点
  vec2 = p3 - p2  # 从顶点指向终点
  angle = arccos(dot(vec1, vec2) / (|vec1| * |vec2|))
  ```
- 返回: 角度值（度），范围 [0, 180]

**`calculate_angles_for_object(class_name, kpt_data, kpt_names, angle_config)`**
- 功能: 为单个对象计算所有角度
- 特点:
  - 自动检查关键点可见性（visibility > 0.5）
  - 处理关键点缺失或不可见的情况
  - 返回详细的角度计算结果，包括错误原因

**`draw_angle_arc(image, p1, p2, p3, radius, color, thickness)`**
- 功能: 在图像上绘制角度弧线
- 实现: 使用OpenCV的ellipse函数绘制圆弧
- 特点: 处理OpenCV角度坐标转换（逆时针→顺时针）

**`annotate_angles_on_image(image, angles_result, keypoints_xy, keypoint_indices_map)`**
- 功能: 在图像上标注角度值
- 特点:
  - 在角度顶点附近显示角度值和名称
  - 绘制绿色角度弧线
  - 使用半透明黑色背景提高文本可读性

## 🔍 关键技术细节

### 1. 角度计算算法

```python
def calculate_angle(p1, p2, p3):
    """计算三点角度（p2为顶点）"""
    vec1 = p1 - p2
    vec2 = p3 - p2
    norm1 = np.linalg.norm(vec1)
    norm2 = np.linalg.norm(vec2)
    cos_angle = np.dot(vec1, vec2) / (norm1 * norm2)
    cos_angle = np.clip(cos_angle, -1.0, 1.0)  # 防止数值误差
    angle_rad = np.arccos(cos_angle)
    angle_deg = np.degrees(angle_rad)
    return float(angle_deg)
```

## ⚠️ 遇到的问题与解决方案

### 问题1: JSON序列化错误

**错误**: `TypeError: Object of type bool is not JSON serializable`

**原因**: NumPy的`numpy.bool_`类型无法直接JSON序列化

**解决方案**:
1. 创建`convert_to_json_serializable()`函数递归转换
2. 显式转换布尔值: `bool(vis > 0.5)`
3. 显式转换索引: `int(idx1), int(idx2), int(idx3)`

### 问题2: OpenCV椭圆绘制角度问题

**问题**: 角度弧线绘制方向不正确

**原因**: OpenCV的ellipse使用顺时针角度，而arctan2返回逆时针角度

**解决方案**: 角度取负并转换为[0, 360)范围

### 问题3: 关键点不可见处理

**需求**: 当关键点不可见时，应跳过角度计算并给出提示

**实现**: 
- 检查三个关键点的visibility值
- 如果任一关键点visibility < 0.5，返回`valid: False`并记录原因
- 在控制台输出详细的错误信息
