## 🎨 视觉设计规范

### 颜色方案

| 元素 | 颜色 | 用途 |
|------|------|------|
| 主标题 | 深蓝色 (#1f4788) | 页面标题 |

## 📱 功能点详细说明

### 1. 摄像头配置区域

#### 1.1 摄像头类型选择（当前版本）
- **类型**: 只读显示或下拉选择（预留）
- **当前值**: "本机摄像头"
- **说明**: 当前版本仅支持本机摄像头，Axis RTSP支持后续添加

#### 1.2 IP地址输入（后续完善）
- **类型**: 文本输入框
- **验证**: 检查IP格式（正则表达式）
- **占位符**: "192.168.1.100"
- **必填**: 是（仅Axis RTSP模式）
- **状态**: 📝 待实现

#### 1.3 端口输入（后续完善）
- **类型**: 数字输入框
- **默认值**: 554
- **范围**: 1-65535
- **必填**: 是（仅Axis RTSP模式）
- **状态**: 📝 待实现

#### 1.4 流名称输入（后续完善）
- **类型**: 文本输入框
- **默认值**: "stream"
- **必填**: 是（仅Axis RTSP模式）
- **状态**: 📝 待实现

#### 1.5 连接按钮
- **功能**: 连接摄像头
- **状态**:
  - 正常状态: 蓝色按钮
  - 连接中: 灰色，显示"连接中..."
  - 禁用: 已连接时禁用

#### 1.6 断开按钮
- **功能**: 断开摄像头连接
- **状态**: 仅在已连接时可用

#### 1.7 连接状态指示
- **已连接**: ● 绿色圆点 + "已连接"
- **未连接**: ○ 灰色圆点 + "未连接"
- **连接中**: 🔄 旋转图标 + "连接中..."

#### 1.8 状态消息
- **成功**: 绿色背景，显示"✅ 连接成功"
- **失败**: 红色背景，显示"❌ 连接失败: [错误信息]"
- **重试提示**: 黄色背景，显示"⚠️ 连接失败，可点击重试"

### 2. 实时预览区域

#### 2.1 预览画面
- **更新频率**: 约10fps（每100ms更新一次）
- **画面尺寸**: 自适应，最大高度400px
- **占位符**: 未连接时显示"未连接摄像头"
- **格式**: RGB格式（从BGR转换）

#### 2.2 实时性保证
- 使用后台线程持续采集帧
- 使用帧缓存避免阻塞
- 使用定时更新（Gradio的`every`参数）

### 3. 检测参数区域

#### 3.1 置信度阈值
- **类型**: 滑块（Slider）
- **范围**: 0.1 - 0.9
- **步长**: 0.05
- **默认值**: 0.25
- **实时显示**: 当前值显示在滑块上方

#### 3.2 图像尺寸
- **类型**: 下拉选择（Dropdown）
- **选项**: 416, 640, 1280
- **默认值**: 640
- **说明**: 越大精度越高，速度越慢

#### 3.3 其他参数说明
- 显示文本提示："其他参数从 angle_config.yaml 读取"
- 不可修改，但可在配置文件中修改

### 4. 输出配置区域

#### 4.1 输出目录输入
- **类型**: 文本输入框
- **默认值**: "outputs/tool_pose"
- **验证**: 检查路径是否有效
- **占位符**: "outputs/tool_pose"

#### 4.2 设置按钮
- **功能**: 应用输出目录设置
- **验证**: 检查路径，创建目录（如果不存在）
- **反馈**: 显示设置结果

#### 4.3 自动保存选项
- **类型**: 多选框（Checkbox）
- **选项**:
  - ☑ 检测前图片
  - ☑ 检测结果图片
  - ☑ JSON数据
- **默认**: 全部选中
- **说明**: 取消勾选则不保存对应文件

### 5. 操作按钮区域

#### 5.1 开始检测按钮
- **样式**: 主要按钮（大、醒目、蓝色）
- **尺寸**: 宽度100%，高度48px
- **状态**:
  - **可用**: 已连接摄像头时
  - **禁用**: 未连接摄像头时（灰色，显示"请先连接摄像头"）
  - **检测中**: 显示"检测中..."（旋转图标）

#### 5.2 按钮点击行为
- 捕获当前预览帧
- 显示"检测中..."状态
- 执行检测（可能在后台线程）
- 显示结果
- 恢复按钮状态

### 6. 检测结果显示区域

#### 6.1 结果图像
- **尺寸**: 自适应，最大高度400px
- **内容**: YOLO检测结果 + 角度标注
- **格式**: RGB格式（从BGR转换）
- **显示时机**: 点击"开始检测"后显示

#### 6.2 统计信息
- **格式**: Markdown格式
- **内容**:
  - 检测到的对象数量
  - 每个对象的类别
  - 每个对象的有效角度数量
  - 每个角度的数值（保留2位小数）
- **样式**: 列表格式，易读

#### 6.3 状态信息
- **成功**: 绿色背景，显示保存的文件路径
- **失败**: 红色背景，显示错误信息
- **格式**: Markdown，支持链接（如果路径可点击）

## 🎯 交互细节设计

### 1. 连接摄像头流程

1. **连接摄像头**
   - **当前版本**: 点击"连接摄像头"按钮，直接打开本机摄像头（VideoCapture(0)）
   - **后续版本**: 选择摄像头类型后，本机摄像头直接连接，Axis RTSP需要填写IP/端口/流名称

2. **点击连接**
   - 按钮状态变为"连接中..."（灰色，禁用）
   - 状态指示变为"🔄 连接中..."
   - 后台执行连接（最多重试3次）

3. **连接成功**
   - 按钮变为"已连接"（绿色，禁用）
   - 状态指示变为"● 已连接"（绿色）
   - 实时预览开始显示
   - 显示成功消息："✅ 连接成功"

4. **连接失败**
   - 按钮恢复为"连接摄像头"
   - 状态指示变为"○ 未连接"（灰色）
   - 显示错误消息："❌ 连接失败: [错误信息]"
   - 提示："可点击重试"

### 2. 开始检测流程

1. **点击检测**
   - 按钮变为"检测中..."（禁用）
   - 捕获当前预览帧
   - 自动保存检测前图片（如果启用）

2. **执行检测**
   - 后台执行检测（如果耗时）
   - 显示进度提示（可选）

3. **显示结果**
   - 结果图像区域显示检测结果
   - 统计信息区域显示详细信息
   - 状态信息显示保存路径

4. **完成**
   - 按钮恢复为"🔍 开始检测"
   - 可以进行下一次检测

### 3. 实时预览更新

- **更新方式**: Gradio的`every`参数，每100ms更新一次
- **更新函数**: `update_preview()`
- **性能优化**: 
  - 只在已连接时更新
  - 使用帧缓存避免重复读取
  - 控制更新频率避免卡顿

### 4. 错误处理展示

#### 连接失败

```
┌─────────────────────────────────────┐
│ ❌ 连接失败                          │
│                                     │

│                                     │
│ 可能原因:                           │
│ - IP地址错误                        │
│ - 端口不正确                        │
│ - 网络连接问题                      │
│                                     │
│ [重试连接]                          │

```

#### 检测失败

## 📐 响应式设计

### 桌面端（≥1024px）
- 左右布局
- 左侧固定400px，右侧自适应

### 平板端（768px - 1023px）
- 左右布局，但压缩间距
- 字体稍微缩小

### 移动端（<768px）
- 上下布局
- 左侧配置区域在上
- 右侧预览区域在下
- 按钮宽度100%
- 字体适当放大便于触摸
