## 功能概述

### 功能目标

在关键点检测结果图像上绘制角度弧线，用于标注三点形成的角度。目标：
- 绘制内角（< 180度）的弧线
- 确保弧线绘制在正确的一侧（内角侧）
- 支持所有角度范围（0-180度）

### 相关函数

- `draw_angle_arc()` - 绘制角度弧线（已禁用）
- `annotate_angles_on_image()` - 在图像上标注角度（当前仅显示文本和连线）

## 算法分析与问题

### 核心问题

对于三点 p1-p2-p3（p2为顶点），计算出的 `angle_value` 是**无方向的**内角值（0-180度），但需要确定弧线应该绘制在哪个方向（顺时针还是逆时针）。

### OpenCV角度系统

**OpenCV `cv2.ellipse` 的角度定义**：
- 0度在右侧（3点钟方向）
- 顺时针为正方向
- `startAngle` 和 `endAngle` 定义顺时针扫过角度
- 如果 `startAngle < endAngle`，绘制从 start 到 end 的顺时针弧线
- 如果 `startAngle > endAngle`，绘制跨越0度的弧线

**坐标转换**：
- `arctan2` 返回逆时针角度，需要转换为顺时针：`angle_cv = -np.degrees(arctan2(y, x)) % 360`

### 原始算法的问题

#### 问题1：判断条件不够精确

```python
if angle_diff_clockwise <= 180:
    if abs(angle_diff_clockwise - angle_value) < 20:
        end_angle = angle2_cv  # 直接使用angle2
```
- 即使 `angle_diff_clockwise <= 180`，也可能与 `angle_value` 不匹配
- 容差20度太大
- 直接使用 `angle2_cv` 可能导致扫过角度不正确

#### 问题2：反向绘制逻辑不准确

```python
else:
    start_angle = angle2_cv
    end_angle = (start_angle + angle_value) % 360
```
- 反向时没有验证这个方向是否正确
- 可能导致绘制在错误的方向
- 使用 `start_angle + angle_value` 可能不是正确的内角方向

#### 问题3：最终验证过于宽松

```python
if sweep_angle > 180 or abs(sweep_angle - angle_value) > 25:
```
- 容差25度太大
- 可能导致绘制错误的弧线

#### 问题4：重新计算逻辑错误

当扫过角度与 `angle_value` 差距太大时，会重新计算：
- 重新计算时直接使用 `angle1_cv` 作为起始角度，可能不是正确的内角方向
- 这可能导致绘制在外角侧而不是内角侧

### 两个方向的角度差

对于两个向量 vec1 和 vec2：

1. **顺时针方向差**：`diff_cw = (angle2_cv - angle1_cv) % 360`
   - 从 vec1 顺时针到 vec2 的角度

2. **逆时针方向差**：`diff_ccw = (angle1_cv - angle2_cv) % 360`
   - 从 vec2 顺时针到 vec1 的角度（实际上是逆时针）

**内角应该是这两个中较小的那个**（因为内角 <= 180度）

## 优化方案

### 最终优化方案（已实现但已禁用）

#### 核心思路

1. **计算两个方向的角度差**（diff_cw 和 diff_ccw）
2. **选择内角方向**（较小的角度差，必须 < 180度）
3. **直接使用角度值确定起始和结束角度**，而不是通过计算
4. **验证扫过角度确保 < 180度**

#### 算法步骤

```python
# 1. 计算向量方向角（OpenCV格式，顺时针）
angle1_cv = -np.degrees(np.arctan2(vec1[1], vec1[0])) % 360
angle2_cv = -np.degrees(np.arctan2(vec2[1], vec2[0])) % 360

# 2. 计算两个方向的角度差
diff_cw = (angle2_cv - angle1_cv) % 360      # 顺时针方向差（从vec1到vec2）
diff_ccw = (angle1_cv - angle2_cv) % 360     # 逆时针方向差（从vec2到vec1）

# 3. 内角是较小的角度差（必须 < 180度）
# 选择内角方向，并确保该方向更接近angle_value
if diff_cw < 180:
    if diff_ccw < 180:
        # 两个方向都是内角，选择更接近angle_value的
        if abs(diff_cw - angle_value) <= abs(diff_ccw - angle_value):
            # 内角在顺时针方向（从vec1到vec2）
            start_angle = angle1_cv
            end_angle = angle2_cv  # 直接使用angle2_cv，扫过角度 = diff_cw
        else:
            # 内角在逆时针方向（从vec2到vec1），反向绘制
            start_angle = angle2_cv
            end_angle = angle1_cv  # 直接使用angle1_cv，扫过角度 = diff_ccw
    else:
        # 只有顺时针方向是内角
        start_angle = angle1_cv
        end_angle = angle2_cv
elif diff_ccw < 180:
    # 只有逆时针方向是内角，反向绘制
    start_angle = angle2_cv
    end_angle = angle1_cv

# 4. 验证扫过角度（必须是内角 < 180度）
sweep_angle = (end_angle - start_angle) % 360

# 5. 如果扫过角度大于等于180度，说明绘制了外角，需要反向
if sweep_angle >= 180:
    start_angle, end_angle = end_angle, start_angle
    sweep_angle = (end_angle - start_angle) % 360

# 6. 绘制弧线
cv2.ellipse(image, center, (radius, radius), 0, start_angle, end_angle, color, thickness)
```

#### 关键改进

1. **直接使用角度值确定方向**：
   - 不再使用 `start_angle + angle_value` 的方式计算结束角度
   - 直接使用 `angle1_cv` 和 `angle2_cv` 作为起始和结束角度
   - 通过计算角度差来选择正确的内角方向

2. **简化选择逻辑**：
   - 同时检查两个方向的角度差
   - 选择是内角（< 180度）且更接近 `angle_value` 的方向
   - 直接使用对应的角度值作为起始和结束角度

3. **移除有问题的重新计算**：
   - 删除了可能导致方向错误的重新计算逻辑
   - 只保留必要的扫过角度验证（确保 < 180度）

4. **严格验证**：
   - 确保扫过角度 < 180度
   - 如果超过，立即反向

## 问题修复历程

### 阶段1：初始问题发现

**问题**：弧度线可能绘制在外角侧而不是内角侧

**分析**：
- 算法判断逻辑不够精确
- 方向选择可能错误
- 验证容差太大

### 阶段2：优化方案制定

**方案1**：使用角度值精确计算
- 问题：使用 `start_angle + angle_value` 可能导致方向错误

**方案2**：直接使用角度差（最终采用）
- 优点：直接反映两个向量的实际相对位置
- 实现：直接使用 `angle1_cv` 和 `angle2_cv`

**需求变更**：确保只绘制内角（< 180度）

**修改**：
- 添加角度值检查：`if angle_value >= 180: return`
- 验证扫过角度：`if sweep_angle >= 180: 反向`

## 技术细节

### 角度计算

三点角度通过向量夹角公式计算：

```python
vec1 = p1 - p2  # 从顶点指向起点
vec2 = p3 - p2  # 从顶点指向终点
angle = arccos(dot(vec1, vec2) / (|vec1| * |vec2|))
```

返回角度范围：[0, 180度]

### OpenCV椭圆绘制

```python
cv2.ellipse(
    image,
    center,           # 中心点（顶点）
    (radius, radius), # 轴长（圆形）
    0,                # 旋转角度（0度）
    start_angle,      # 起始角度（度，OpenCV顺时针）
    end_angle,        # 结束角度（度，OpenCV顺时针）
    color,            # 颜色 (BGR)
    thickness         # 线条粗细
)
```

### 角度转换公式

从标准数学角度（逆时针）转换为OpenCV角度（顺时针）：

```python
angle_cv = -np.degrees(np.arctan2(y, x)) % 360
```
