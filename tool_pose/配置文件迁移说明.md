## ✅ 迁移内容

### 配置文件位置变更

- **原位置**: `tool_pose/demo/angle_config.yaml`
- **新位置**: `src/yolo_detector/config/tool_pose_config.yaml`

### 配置参数合并

新配置文件合并了以下所有配置参数：

1. **路径配置** (`paths`)
   - `model`: 模型文件路径
   - `output`: 输出目录

2. **预测参数** (`predict`)
   - `conf`: 置信度阈值
   - `iou`: IoU阈值
   - `imgsz`: 图像尺寸
   - `device`: 设备选择
   - `half`: 半精度推理
   - `max_det`: 最大检测数量

3. **输出选项** (`output`)
   - `show_image`: 是否显示结果图片
   - `save_image`: 是否保存标注后的图片
   - `save_json`: 是否保存JSON结果文件
   - `save_raw_image`: 是否保存检测前原始图片

4. **类别和关键点配置**
   - `names`: 类别名称映射
   - `kpt_names`: 关键点名称映射
   - `keypoints`: 关键点详细配置
     - `kpt_shape`: 关键点形状
     - `num_classes`: 类别数量
     - `skeleton`: 骨架连接
     - `flip_idx`: 水平翻转索引
     - `pose_weights`: 关键点权重

5. **角度定义** (`angles`)
   - 每个工具的角度定义（由三个关键点名称组成）

6. **可视化参数** (`visualization`)
   - `kpt_radius`: 关键点绘制半径
   - `kpt_line`: 是否绘制骨架连线
   - `labels`: 是否显示标签
   - `boxes`: 是否显示边界框
   - `line_width`: 边界框线条宽度
   - `angle_font_size`: 角度标注字体大小
   - `angle_color`: 角度标注颜色

7. **摄像头配置** (`camera`) - **新增**
   - `index`: 摄像头索引
   - `width`: 摄像头宽度
   - `height`: 摄像头高度
   - `preview_interval`: 预览刷新间隔
   - `auto_refresh`: 是否自动刷新预览

8. **日志配置** (`logging`) - **新增**
   - `level`: 日志级别
   - `file`: 日志文件路径
   - `max_size`: 日志文件大小限制
   - `retention_days`: 日志文件保留天数

## 📝 配置文件使用方式

### 默认使用

如果不指定配置文件路径，系统会自动使用默认配置文件：

```python
from yolo_detector.utils import ToolPoseDetector

# 使用默认配置文件
detector = ToolPoseDetector()
```

默认配置文件路径：`src/yolo_detector/config/tool_pose_config.yaml`

### 自定义配置文件

可以指定自定义配置文件路径：

```python
# 使用自定义配置文件
detector = ToolPoseDetector(config_path="path/to/custom_config.yaml")
```

### 命令行使用

```bash
# 使用默认配置文件
python main.py web

# 指定自定义配置文件
python main.py web --config path/to/custom_config.yaml
```
