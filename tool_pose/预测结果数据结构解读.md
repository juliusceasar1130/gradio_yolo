## 🎯 概述

YOLO11 Pose 模型的 `predict()` 方法返回一个 `Results` 列表，每个元素是单张图像的预测结果。对于单张图像，我们通常使用 `results[0]` 来获取结果对象 `result`。

### Result 对象核心属性

```python
results = model.predict(image_path)
result = results[0]  # 单张图像的结果

# Result 对象主要包含：
# - result.boxes: 边界框信息（位置、类别、置信度）
# - result.keypoints: 关键点信息（坐标、可见性）
# - result.plot(): 可视化方法
# - result.orig_shape: 原始图像尺寸
# - result.path: 图像路径
```

## 📦 Result 对象结构

### 完整属性列表

| 属性名 | 类型 | 说明 |
|--------|------|------|
| `boxes` | Boxes | 检测到的边界框信息 |
| `keypoints` | Keypoints | 检测到的关键点信息 |
| `orig_shape` | tuple | 原始图像尺寸 (height, width) |
| `path` | str | 图像文件路径 |
| `names` | dict | 类别名称字典 |
| `probs` | Probs | 分类概率（分类任务） |
| `speed` | dict | 推理速度统计 |

### 基础访问示例

```python
# 获取结果对象
result = results[0]

# 基本信息
print(f"图像路径: {result.path}")
print(f"图像尺寸: {result.orig_shape}")  # (height, width)
print(f"类别名称: {result.names}")

# 检测信息
print(f"检测到 {len(result.boxes)} 个对象")
print(f"检测到 {len(result.keypoints)} 组关键点")
```

## 🎯 Boxes（边界框）数据详解

### Boxes 对象结构

`result.boxes` 是一个 `Boxes` 对象，包含所有检测到的边界框信息。

### 主要属性

| 属性名 | 类型 | 说明 | 维度 |
|--------|------|------|------|
| `xyxy` | Tensor | 边界框坐标（左上角+右下角） | [N, 4] |
| `xywh` | Tensor | 边界框坐标（中心点+宽高） | [N, 4] |
| `xyxyn` | Tensor | 归一化坐标（左上角+右下角，0-1范围） | [N, 4] |
| `xywhn` | Tensor | 归一化坐标（中心点+宽高，0-1范围） | [N, 4] |
| `conf` | Tensor | 置信度分数 | [N] |
| `cls` | Tensor | 类别ID | [N] |
| `data` | Tensor | 完整数据 [x1,y1,x2,y2,conf,cls] | [N, 6] |

### 坐标格式说明

#### 1. xyxy 格式（绝对坐标）
```python
# 格式: [x1, y1, x2, y2]
# x1, y1: 左上角坐标
# x2, y2: 右下角坐标
# 单位: 像素

boxes_xyxy = result.boxes.xyxy  # Tensor shape: [N, 4]
# 示例: tensor([[100., 50., 200., 150.],  # 对象1的边界框
#               [300., 200., 400., 300.]]) # 对象2的边界框
```

#### 2. xywh 格式（绝对坐标）
```python
# 格式: [center_x, center_y, width, height]
# center_x, center_y: 中心点坐标
# width, height: 宽度和高度
# 单位: 像素

boxes_xywh = result.boxes.xywh  # Tensor shape: [N, 4]
# 示例: tensor([[150., 100., 100., 100.],  # 对象1: 中心(150,100), 大小100x100
#               [350., 250., 100., 100.]])  # 对象2: 中心(350,250), 大小100x100
```

#### 3. xyxyn 格式（归一化坐标）
```python
# 格式: [x1_norm, y1_norm, x2_norm, y2_norm]
# 坐标范围: 0.0 - 1.0（相对于图像尺寸）
# 便于不同尺寸图像处理

boxes_xyxyn = result.boxes.xyxyn  # Tensor shape: [N, 4]
# 假设图像尺寸 640x480
# 示例: tensor([[0.156, 0.104, 0.313, 0.313],  # 归一化后的坐标
#               [0.469, 0.417, 0.625, 0.625]])
```

#### 4. xywhn 格式（归一化坐标）
```python
# 格式: [center_x_norm, center_y_norm, width_norm, height_norm]
# 坐标范围: 0.0 - 1.0

boxes_xywhn = result.boxes.xywhn  # Tensor shape: [N, 4]
```

### 访问单个边界框

```python
# 方式1: 直接索引
if len(result.boxes) > 0:
    first_box = result.boxes[0]
    cls = int(first_box.cls[0])        # 类别ID
    conf = float(first_box.conf[0])    # 置信度
    xyxy = first_box.xyxy[0].tolist()  # [x1, y1, x2, y2]
    
    print(f"类别: {cls}, 置信度: {conf:.3f}")
    print(f"边界框: {xyxy}")

# 方式2: 遍历所有边界框
for i, box in enumerate(result.boxes):
    cls = int(box.cls[0])
    conf = float(box.conf[0])
    xyxy = box.xyxy[0].cpu().numpy()
    
    print(f"对象 {i+1}: 类别={cls}, 置信度={conf:.3f}, 位置={xyxy}")
```

### 转换为 NumPy 数组

```python
# 转换为 NumPy 数组（CPU上）
boxes_xyxy_np = result.boxes.xyxy.cpu().numpy()  # shape: [N, 4]
conf_np = result.boxes.conf.cpu().numpy()        # shape: [N]
cls_np = result.boxes.cls.cpu().numpy().astype(int)  # shape: [N]

# 获取第一个对象的完整信息
if len(boxes_xyxy_np) > 0:
    x1, y1, x2, y2 = boxes_xyxy_np[0]
    conf = conf_np[0]
    cls = cls_np[0]
    
    print(f"对象1: 类别={cls}, 置信度={conf:.3f}")
    print(f"位置: ({x1:.1f}, {y1:.1f}) -> ({x2:.1f}, {y2:.1f})")
```

## 🦴 Keypoints（关键点）数据详解

### Keypoints 对象结构

`result.keypoints` 是一个 `Keypoints` 对象，包含所有检测到的关键点信息。每个检测到的对象对应一组关键点。

### 主要属性

| 属性名 | 类型 | 说明 | 维度 |
|--------|------|------|------|
| `data` | Tensor | 关键点数据 [x, y, visibility] | [N, num_keypoints, 3] |
| `xy` | Tensor | 关键点坐标（像素坐标） | [N, num_keypoints, 2] |
| `xyn` | Tensor | 关键点坐标（归一化，0-1） | [N, num_keypoints, 2] |
| `conf` | Tensor | 关键点置信度/可见性 | [N, num_keypoints] |

### 数据格式说明

#### 关键点维度

```python
# YOLO11 Pose 默认使用 COCO 17 关键点格式
NUM_KEYPOINTS = 17

# 关键点索引定义（COCO格式）
KEYPOINT_NAMES = [
    0: "鼻子",     1: "左眼",     2: "右眼",     3: "左耳",     4: "右耳",
    5: "左肩",     6: "右肩",     7: "左肘",     8: "右肘",     9: "左腕",    10: "右腕",
    11: "左髋",    12: "右髋",    13: "左膝",    14: "右膝",    15: "左踝",   16: "右踝"
]
```

#### data 属性详解

```python
# result.keypoints.data 的形状: [N, 17, 3]
# N: 检测到的对象数量
# 17: 关键点数量
# 3: [x坐标, y坐标, 可见性标志]

keypoints_data = result.keypoints.data  # Tensor shape: [N, 17, 3]

# 示例数据格式:
# tensor([
#     # 对象1的关键点 (17个关键点)
#     [[150.2, 100.5, 2.0],   # 关键点0 (鼻子): x=150.2, y=100.5, 可见=2
#      [145.1,  95.3, 2.0],   # 关键点1 (左眼): x=145.1, y=95.3,  可见=2
#      [155.3,  95.1, 2.0],   # 关键点2 (右眼): x=155.3, y=95.1,  可见=2
#      ...
#      [0.0,    0.0,  0.0]],  # 关键点16 (右踝): 未检测到，坐标为(0,0)，可见=0
#     
#     # 对象2的关键点
#     [[...], [...], ...]
# ])
```

#### 可见性标志说明

| 值 | 含义 | 说明 |
|----|------|------|
| `0.0` | 不可见/未标注 | 关键点未检测到或被遮挡 |
| `1.0` | 部分遮挡 | 关键点部分可见但可能不准确 |
| `2.0` | 完全可见 | 关键点清晰可见且检测准确 |

#### xy 属性（像素坐标）

```python
# result.keypoints.xy 只包含坐标信息，形状: [N, 17, 2]
# [x, y] 格式，单位：像素

keypoints_xy = result.keypoints.xy  # Tensor shape: [N, 17, 2]

# 获取第一个对象的所有关键点坐标
if len(keypoints_xy) > 0:
    kpts_xy = keypoints_xy[0].cpu().numpy()  # shape: [17, 2]
    
    for i, (x, y) in enumerate(kpts_xy):
        if x > 0 and y > 0:  # 过滤无效关键点
            print(f"关键点{i}: ({x:.1f}, {y:.1f})")
```

#### xyn 属性（归一化坐标）

```python
# result.keypoints.xyn 归一化坐标，形状: [N, 17, 2]
# 坐标范围: 0.0 - 1.0（相对于图像尺寸）

keypoints_xyn = result.keypoints.xyn  # Tensor shape: [N, 17, 2]

# 归一化坐标便于处理不同尺寸的图像
```

#### conf 属性（可见性置信度）

```python
# result.keypoints.conf 可见性置信度，形状: [N, 17]
# 对应每个关键点的可见性标志值

keypoints_conf = result.keypoints.conf  # Tensor shape: [N, 17]

# 获取第一个对象的关键点可见性
if len(keypoints_conf) > 0:
    visibilities = keypoints_conf[0].cpu().numpy()  # shape: [17]
    
    for i, vis in enumerate(visibilities):
        if vis > 0.5:  # 可见性阈值
            print(f"关键点{i}: 可见 (置信度={vis:.1f})")
```

### 访问单个关键点组

```python
# 方式1: 直接索引
if len(result.keypoints) > 0:
    first_kpts = result.keypoints[0]
    kpt_data = first_kpts.data.cpu().numpy()  # shape: [17, 3]
    
    # 遍历所有关键点
    for i, (x, y, vis) in enumerate(kpt_data):
        if vis > 0.5:  # 只处理可见的关键点
            print(f"关键点{i}: ({x:.1f}, {y:.1f}), 可见性={vis:.1f}")

# 方式2: 遍历所有对象的关键点
for i, kpts in enumerate(result.keypoints):
    kpt_data = kpts.data.cpu().numpy()
    
    # 统计可见关键点数量
    visible_count = sum(1 for _, _, vis in kpt_data if vis > 0.5)
    print(f"对象 {i+1}: {visible_count}/17 个关键点可见")
```

### 按对象关联数据

```python
# 将边界框和关键点信息关联起来
def parse_pose_results(result):
    """解析 Pose 预测结果，将边界框和关键点关联"""
    
    detections = []
    
    if result.boxes is None or len(result.boxes) == 0:
        return detections
    
    # 获取所有边界框和关键点数据
    boxes_xyxy = result.boxes.xyxy.cpu().numpy()
    boxes_conf = result.boxes.conf.cpu().numpy()
    boxes_cls = result.boxes.cls.cpu().numpy().astype(int)
    
    if result.keypoints is not None and len(result.keypoints) > 0:
        keypoints_data = result.keypoints.data.cpu().numpy()
    else:
        keypoints_data = None
    
    # 遍历每个检测到的对象
    for i in range(len(result.boxes)):
        detection = {
            'object_id': i,
            'class_id': int(boxes_cls[i]),
            'class_name': result.names[int(boxes_cls[i])],
            'confidence': float(boxes_conf[i]),
            'bbox': {
                'x1': float(boxes_xyxy[i][0]),
                'y1': float(boxes_xyxy[i][1]),
                'x2': float(boxes_xyxy[i][2]),
                'y2': float(boxes_xyxy[i][3]),
                'width': float(boxes_xyxy[i][2] - boxes_xyxy[i][0]),
                'height': float(boxes_xyxy[i][3] - boxes_xyxy[i][1])
            }
        }
        
        # 添加关键点信息
        if keypoints_data is not None and i < len(keypoints_data):
            kpt_data = keypoints_data[i]  # [17, 3]
            keypoints = []
            
            for kpt_idx, (x, y, vis) in enumerate(kpt_data):
                keypoints.append({
                    'index': kpt_idx,
                    'x': float(x),
                    'y': float(y),
                    'visibility': float(vis),
                    'visible': vis > 0.5
                })
            
            detection['keypoints'] = keypoints
            detection['visible_keypoints'] = sum(1 for kp in keypoints if kp['visible'])
        
        detections.append(detection)
    
    return detections

# 使用示例
detections = parse_pose_results(result)

for det in detections:
    print(f"\n对象 {det['object_id'] + 1}:")
    print(f"  类别: {det['class_name']} (ID: {det['class_id']})")
    print(f"  置信度: {det['confidence']:.3f}")
    print(f"  边界框: ({det['bbox']['x1']:.1f}, {det['bbox']['y1']:.1f}) "
          f"-> ({det['bbox']['x2']:.1f}, {det['bbox']['y2']:.1f})")
    
    if 'keypoints' in det:
        print(f"  可见关键点: {det['visible_keypoints']}/17")
```

## 🔧 实际应用场景

### 场景1: 关键点坐标提取

```python
def extract_keypoints(result, object_index=0):
    """提取指定对象的关键点坐标"""
    
    if result.keypoints is None or len(result.keypoints) == 0:
        return None
    
    if object_index >= len(result.keypoints):
        return None
    
    kpts = result.keypoints[object_index]
    kpt_data = kpts.data.cpu().numpy()  # [17, 3]
    
    # 只返回可见的关键点
    visible_keypoints = []
    for kpt_idx, (x, y, vis) in enumerate(kpt_data):
        if vis > 0.5:
            visible_keypoints.append({
                'index': kpt_idx,
                'x': float(x),
                'y': float(y),
                'visibility': float(vis)
            })
    
    return visible_keypoints

# 使用
visible_kpts = extract_keypoints(result, object_index=0)
if visible_kpts:
    print(f"提取到 {len(visible_kpts)} 个可见关键点")
```

### 场景2: 计算关键点距离

```python
def calculate_keypoint_distance(result, obj_idx, kpt1_idx, kpt2_idx):
    """计算两个关键点之间的距离"""
    
    if result.keypoints is None:
        return None
    
    kpts = result.keypoints[obj_idx]
    kpt_data = kpts.data.cpu().numpy()
    
    x1, y1, vis1 = kpt_data[kpt1_idx]
    x2, y2, vis2 = kpt_data[kpt2_idx]
    
    if vis1 < 0.5 or vis2 < 0.5:
        return None  # 关键点不可见
    
    distance = np.sqrt((x2 - x1)**2 + (y2 - y1)**2)
    return distance

# 示例：计算左右肩的距离
shoulder_distance = calculate_keypoint_distance(result, 0, 5, 6)
if shoulder_distance:
    print(f"左右肩距离: {shoulder_distance:.2f} 像素")
```

### 场景3: 保存结果到文件

```python
import json

def save_pose_results(result, output_file):
    """保存预测结果到 JSON 文件"""
    
    output_data = {
        'image_path': result.path,
        'image_shape': result.orig_shape,
        'detections': []
    }
    
    if result.boxes is not None:
        boxes_xyxy = result.boxes.xyxy.cpu().numpy()
        boxes_conf = result.boxes.conf.cpu().numpy()
        boxes_cls = result.boxes.cls.cpu().numpy().astype(int)
        
        keypoints_data = None
        if result.keypoints is not None:
            keypoints_data = result.keypoints.data.cpu().numpy()
        
        for i in range(len(result.boxes)):
            det = {
                'object_id': i,
                'class_id': int(boxes_cls[i]),
                'class_name': result.names[int(boxes_cls[i])],
                'confidence': float(boxes_conf[i]),
                'bbox': {
                    'x1': float(boxes_xyxy[i][0]),
                    'y1': float(boxes_xyxy[i][1]),
                    'x2': float(boxes_xyxy[i][2]),
                    'y2': float(boxes_xyxy[i][3])
                }
            }
            
            if keypoints_data is not None:
                kpt_data = keypoints_data[i]
                det['keypoints'] = []
                for kpt_idx, (x, y, vis) in enumerate(kpt_data):
                    det['keypoints'].append({
                        'index': int(kpt_idx),
                        'x': float(x),
                        'y': float(y),
                        'visibility': float(vis)
                    })
            
            output_data['detections'].append(det)
    
    with open(output_file, 'w', encoding='utf-8') as f:
        json.dump(output_data, f, indent=2, ensure_ascii=False)
    
    print(f"结果已保存到: {output_file}")

# 使用
save_pose_results(result, "pose_results.json")
```

## 📊 数据维度总结

### Boxes 数据维度

| 属性 | 维度 | 说明 |
|------|------|------|
| `boxes.xyxy` | [N, 4] | N 个对象，每个对象 4 个坐标值 |
| `boxes.conf` | [N] | N 个置信度分数 |
| `boxes.cls` | [N] | N 个类别ID |
| `boxes.data` | [N, 6] | N 个对象，每个对象 6 个值 [x1,y1,x2,y2,conf,cls] |

### Keypoints 数据维度

| 属性 | 维度 | 说明 |
|------|------|------|
| `keypoints.data` | [N, 17, 3] | N 个对象，每个对象 17 个关键点，每个关键点 3 个值 [x,y,vis] |
| `keypoints.xy` | [N, 17, 2] | N 个对象，每个对象 17 个关键点的 [x,y] 坐标 |
| `keypoints.conf` | [N, 17] | N 个对象，每个对象 17 个关键点的可见性 |

### 重要提示

1. **数据类型**: 所有数据都是 PyTorch Tensor，需要 `.cpu().numpy()` 转换为 NumPy 数组
2. **坐标系统**: 图像坐标系，原点在左上角，x 轴向右，y 轴向下
3. **归一化**: `*n` 后缀的属性是归一化坐标（0-1 范围）
4. **设备位置**: Tensor 可能在 GPU 上，需要先移到 CPU 再转换

if result.keypoints is not None and len(result.keypoints) > 0:

    visible_count = visible_mask.sum()
